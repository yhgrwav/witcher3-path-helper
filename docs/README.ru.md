# Board Taker — The Witcher 3 (next-gen)

[English](../README.md) · **Русский**

Консольные команды, которые забирают все заказы и объявления с досок, включая полностью автоматический обход всех досок текущего региона. Удобно, если у вас открыты все точки быстрого перемещения и вы уже не помните, какие доски проверяли.

Квесты берутся через собственный код досок игры, поэтому появляются в журнале так же, как если бы вы сорвали объявление сами.

## Требования

- The Witcher 3: Wild Hunt next-gen (4.0 и новее, используются аннотации скриптов)
- Включённая консоль (`DBGConsoleOn=true` в `bin\config\base\general.ini` или любой мод на консоль)

## Установка

Скопируйте папку `modZBoardTaker` в `The Witcher 3\Mods`. Мерж не нужен, ванильные файлы не меняются.

## Команды

| Команда | Что делает |
|---|---|
| `bauto()` | Автообход: телепорт к каждой доске с отметкой NEW в текущем регионе (~4 с на доску) и сбор всех квестов |
| `bauto(true)` | То же, но по всем доскам |
| `bstop()` | Остановить обход |
| `btake()` | Забрать квесты со всех загруженных досок вокруг (~2 км) |
| `blist()` | Доски региона, ближайшие первыми. `blist(1)` — следующая страница |
| `bgo(N)` | Телепорт к доске N из `blist()` |
| `btour()` | Телепорт к ближайшей доске, где ещё есть квесты |

## Примечания

- Работает только в текущем мире (Велен/Новиград, Скеллиге, Туссент и т. д. — разные миры). Запустите `bauto()` по разу в каждом регионе.
- Если доска не прогрузилась за 4 секунды, запустите `bauto()` ещё раз — он пройдёт только по доскам, где что-то осталось.
- Доска может остаться NEW, если часть объявлений ещё не открыта по сюжету.
- Во время боя обход ставится на паузу.
