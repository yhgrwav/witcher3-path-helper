# Board Taker — The Witcher 3 (next-gen)

[English](../README.md) · **Українська**

Консольні команди, які забирають усі замовлення та оголошення з дошок, зокрема повністю автоматичний обхід усіх дошок поточного регіону. Зручно, якщо у вас відкриті всі точки швидкого переміщення і ви вже не пам'ятаєте, які дошки перевіряли.

Квести беруться через власний код дошок гри, тож з'являються в журналі так само, ніби ви зірвали оголошення самі.

## Вимоги

- The Witcher 3: Wild Hunt next-gen (4.0 і новіше, використовуються анотації скриптів)
- Увімкнена консоль (`DBGConsoleOn=true` у `bin\config\base\general.ini` або будь-який мод на консоль)

## Встановлення

Скопіюйте теку `modZBoardTaker` у `The Witcher 3\Mods`. Мерж не потрібен, ванільні файли не змінюються.

## Команди

| Команда | Що робить |
|---|---|
| `bauto()` | Автообхід: телепорт до кожної дошки з позначкою NEW у регіоні (~4 с на дошку) і збір усіх квестів |
| `bauto(true)` | Те саме, але по всіх дошках |
| `bstop()` | Зупинити обхід |
| `btake()` | Забрати квести з усіх завантажених дошок довкола (~2 км) |
| `blist()` | Дошки регіону, найближчі першими. `blist(1)` — наступна сторінка |
| `bgo(N)` | Телепорт до дошки N з `blist()` |
| `btour()` | Телепорт до найближчої дошки, де ще є квести |

## Примітки

- Працює лише в поточному світі (Велен/Новіград, Скелліге, Туссент тощо — різні світи). Запустіть `bauto()` по разу в кожному регіоні.
- Якщо дошка не завантажилась за 4 секунди, запустіть `bauto()` ще раз — він пройде лише дошками, де щось лишилося.
- Дошка може лишитися NEW, якщо частина оголошень ще не відкрита за сюжетом.
- Під час бою обхід стає на паузу.
